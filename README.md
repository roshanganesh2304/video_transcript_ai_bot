# Video Transcript Chatbot (YT Transcript Chatbot)

A FastAPI & JavaScript web application for processing YouTube and local video transcripts, building vector RAG embeddings, and interacting via AI chat.

## Features
- Process YouTube videos and local video/SRT files.
- Vector search & RAG pipeline with PostgreSQL / Ollama LLM integration.
- Dynamic web interface with transcription search and interactive chat.

## Setup & Running
```bash
./run.sh
```
